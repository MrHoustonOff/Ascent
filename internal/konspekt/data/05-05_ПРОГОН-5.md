**Должен знать**
Рассказ строй сверху вниз: `cmd/app/main.go` читает настройки из окружения и собирает зависимости; обработчики `net/http` разбирают запрос и переводят ошибки в коды; сервис держит правила и границы транзакций; репозиторий на `pgx` — SQL с плейсхолдерами; миграции отдельным шагом; плавная остановка по SIGTERM. Тесты: табличные тесты сервиса на фейке, тесты обработчиков через `httptest`, тесты репозитория с testcontainers, всё под `-race`.
Программа: `compose.yaml` с Postgres; миграция таблицы; интерфейс репозитория в пакете сервиса; `TestService` с таблицей случаев (успех, «не найдено», ошибка базы); `TestRepo` поднимает `postgres:16` через testcontainers в `TestMain`.
