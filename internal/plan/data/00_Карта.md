# Go — ROADMAP v2: карта

Путь от полного нуля до готовности к собесу стажёра или джуна Go-бэкенда (Озон, Авито, WB, Т-Банк, Яндекс). Всё объясняется с нуля: Go, память, SQL, сеть, веб, брокеры. План самодостаточный: каждую строку отдаёшь Гермесу, и его ответ — твой единственный источник.

Чего здесь нет намеренно:
- **алгоритмов** — это Афина;
- **практики** — её даёт Гермес;
- **пет-проектов**, кроме одного финального. Для него два ТЗ на выбор: [[98 ТЗ А — Распродажа без перепродажи]] и [[99 ТЗ Б — Доставка вебхуков]].

**Статус:** основной путь написан целиком: 7 этапов, 61 блок, 932 урока. У каждой из 180 тем есть блок «Должен уметь ответить» — всего 720 вопросов самопроверки. Банк вопросов с собесов собран (419 вопросов, у каждого блока есть маркеры ◆), звёзды пересчитаны по нему скриптом. План прошёл полную ревизию: факты сверены с release notes Go 1.26 и 1.27, стек — с разборами стажировок Озона и WB. Оба ТЗ переведены на номера уроков этого плана. Рассчитан на Go 1.27.

## Как пользоваться

1. Иди строго сверху вниз: этап → блок → тема → урок.
2. Перед первым уроком темы прочитай её **бриф** (строки `>` под заголовком): что учим и зачем.
3. **Урок — одна строка с чекбоксом.** Отдаёшь Гермесу бриф темы и строку урока вместе со строками `↳` под ней. Содержание урока пишет он.
4. Урок прошёл — ставишь галочку.
5. **Тема закрыта, когда ты отвечаешь вслух на все вопросы её блока «Должен уметь ответить»** — без конспекта, своими словами. Ответил — ставишь галочку у вопроса. Не можешь ответить — возвращаешься к уроку этой темы. Гермес может задать эти вопросы как проверку в конце темы.
6. Если в уроке тема совпадает с Python, просто проходишь её быстрее, но не пропускаешь.
7. В конце блока отвечаешь вслух, без конспекта, на маркеры ◆ его раздела в [[90 Банк вопросов]]. Ответил на все — блок закрыт. Не ответил — возвращаешься к урокам, указанным после стрелки.
8. В конце этапа проходишь **ПРОГОН**: устный мини-собес без нового материала.

**Пример того, что отдать Гермесу:**
```
Тема GO-2.1 Переменная
> В Python переменная — это имя, приклеенное к объекту. В Go переменная — это сам
> кусок памяти. Это различие объясняет половину будущих вопросов «что выведет код».
Урок GO-2.1.5 — Присваивание и копирование значений ★★
  ↳ мост: присваивание в Python
```

## Правила, по которым написан план

0. **Строка урока — заголовок параграфа, а не ответ.** «Деление целого на ноль и паника», а не «…: программа аварийно останавливается». Что там происходит, рассказывает Гермес. То же с мостами: `↳ мост: присваивание в Python` говорит, с чем сравнить, но не само сравнение.
1. **Одна новая сущность на урок.** Если в строке урока два незнакомых слова, это два урока. Исключение — **уроки-карты**: они называют набор частей целиком, например «код, данные, стек, куча» в ФУНД-3.2.2, а сами части разбирают следующие уроки.
2. **Только пройденные слова.** Строка урока, бриф и граница используют только термины, которые уже объяснены, плюс одну новую сущность. Будущее можно упомянуть только в строке `↳ позже:`.
3. **Словарь проверяет это скриптом.** В [[91 Словарь]] каждый термин привязан к уроку, где он появляется впервые. `tools/check_plan.py` падает, если термин встретился раньше своего урока.
4. **Бриф перед каждой темой:** 1–3 предложения о том, что учим и зачем, тоже только знакомыми словами.
5. **Пирамида блоков:** строка «стоит на» у блока и `↳ стоит на` у урока — без этого их не учат.
6. **Всё с нуля.** Сравнения с Python (`↳ мост`) помогают пройти быстрее, но материал не сокращают.

## Легенда

| Знак | Значение |
|---|---|
| **ID** `GO-2.1.5` | трек-блок.тема.урок. Треки: ФУНД (машина и ОС), GO, SQL, PG (устройство Postgres), СЕТЬ, ОС (Linux), АРХ (архитектура), ТЕСТ, ИНФРА (Docker, кэш, наблюдаемость, CI/CD, Kubernetes), БРОК (брокеры: Kafka и RabbitMQ), СИСД (системный дизайн), СБОР (сборка к собесу), ПРОГОН |
| `> …` под темой | бриф: что учим и зачем |
| **Должен уметь ответить** | вопросы самопроверки в конце темы: на них ты отвечаешь вслух, прежде чем идти дальше. В них только слова, которые к этому моменту уже пройдены |
| *Зачем* под блоком | зачем весь блок |
| ★★★ | вопросы урока встретились минимум в двух независимых источниках банка или это известная ловушка «что выведет код» |
| ★★ | у урока есть вопрос в банке: из одного источника или типовой |
| ★ | отдельно не спрашивают, но урок — опора для соседних |
| без звёзд | синтаксис и инструменты: их не спрашивают, ими пользуются |
| `↳ мост:` | с чем в Python и CPython сравнить (само сравнение делает Гермес) |
| `↳ граница:` | стоп-линия: дальше не идём, Гермес закрывает это одной фразой |
| `↳ позже:` | где эта тема продолжится; здесь её **не** учим |
| `↳ стоит на:` | урок опирается на конкретный более ранний урок |
| `↳ PhoneGyro:` | живой пример из твоего проекта |
| `↳ версия:` | что поменялось в свежих версиях Go |

## Темп

Уроков вышло 932 — больше прежней оценки (650–800), потому что каждое незнакомое слово стало отдельным уроком. Уроки маленькие: одна сущность, 2–4 шага у Гермеса. Синтаксические уроки этапа 1 будут идти заметно быстрее уроков про рантайм.

Прогноз от старта 26 октября 2026 года:

| Уроков в день | Веха (542 урока) | Весь путь (932) |
|---|---|---|
| 5 | 12 февраля 2027 | 1 мая 2027 |
| 7 | 12 января 2027 | 9 марта 2027 |
| 10 | 20 декабря 2026 | 28 января 2027 |

Это арифметика, а не обещание. Первые 20–30 уроков просто считай, сколько проходишь в день, и по факту выбери строку таблицы.

**Если темп ниже нужного,** уроки не выкидывай. Сначала режутся пункты «Если останется время» в ТЗ. Потом можно идти на собесы сразу после вехи, а этапы 4–7 проходить параллельно с откликами.

**Когда подаваться** (даты наборов уточняй на сайтах компаний, они сдвигаются):
- **сейчас** — Озон (открыты Go-стажировки) и Яндекс (бэкенд, контест на любом языке). Это практика контестов и собесов, даже если ты ещё не готов;
- **после вехи** — Т-Банк (Т-Старт), WB (весенняя волна обычно февраль–апрель), Авито (весенний набор), VK. Это основная ставка.

## Для Гермеса: правки в teaching.md

1. **Цель** (строка 3):
   > The learner is an IT student starting Go from zero. Goal: get an internship or junior position as a **Go backend developer** (Ozon, Avito, Wildberries, T-Bank, Yandex), as a real specialist with solid fundamentals. Python is the learner's previous language: use CPython as a bridge when comparing, but never skip material because it is "like Python".
2. **Tier 1**, вопрос про собес:
   > Will a **Go intern or junior** interview ask about it?
3. **Раздел 2:** в скобках заменить `(Python, SQL, shell, HTTP)` на `(Go, SQL, shell, HTTP)`.
4. **Раздел 11:** добавить «state the Go version for runtime and library facts».
5. **Новый абзац в раздел 4:**
   > Lessons come from the Go — ROADMAP plan. Each theme ends with a «Должен уметь ответить» checklist: after the theme's last lesson, ask these questions one by one as the closing check; the learner answers aloud in their own words, and any miss sends them back to the matching lesson. Each lesson introduces exactly one new concept; teach that concept and nothing new beyond it. The theme brief (lines starting with ">") says why the theme matters — use it as the hook. `↳ граница` is a hard stop (tier 3, one bridging sentence). `↳ позже` names where a topic continues — do not teach it now, only say where it comes. `↳ мост` is a required CPython comparison. Prerequisites in «стоит на» must be checked with covered.py before step 1.

## Проверка плана

```
python tools/check_plan.py
```

Скрипт проверяет:
- пирамиду блоков и уроков;
- иерархию ID;
- словарную пирамиду: ни один термин не встречается раньше своего урока;
- банк вопросов: каждый урок с ★★ или ★★★ закрывает вопрос, у каждого блока не меньше двух ◆;
- что у каждой темы есть хотя бы два вопроса «Должен уметь ответить» и в них нет слов, которые ещё не пройдены;
- что все номера уроков в ТЗ существуют.

Звёзды пересчитывает отдельный скрипт по банку вопросов:
```
python tools/stars.py          # показать, что изменится
python tools/stars.py --write  # записать
```
