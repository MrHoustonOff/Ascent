Однострочное поле ввода с подписью и подсказкой.

Предоставьте: `label`, `placeholder`, текст подсказки или ошибки.

- Подпись всегда над полем в `as-label`. Плейсхолдер — пример, не замена подписи.
- Ошибка: `aria-invalid="true"` и текст `as-hint--error`. Сообщение говорит, что исправить: «Укажите хотя бы 5 минут».
- Фокус рисуется рамкой `accent` и мягким кольцом `accent-soft`; не убирайте его.
