Само окно: скругление `radius-window`, тень `shadow-window`, шапка сверху и тело `as-window__body` со списком уроков и рабочей областью.

Предоставьте: размер окна контейнером. Класс `is-maximized` убирает скругление и тень не нужна.

- Фон окна — `surface-window`; карточки лежат на нём.
- Тело делится на `as-sidebar` и `as-window__main`; основная область прокручивается, шапка нет.
- Окно всегда имеет внешнюю обводку в `shadow-window` — на тёмном рабочем столе без неё оно теряется.
