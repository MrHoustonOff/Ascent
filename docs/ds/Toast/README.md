Тихое сообщение поверх экрана: поощрение или подтверждение.

Предоставьте: заголовок, при необходимости одну строку и кнопку «Ок».

- Появляется внизу или справа, исчезает сам через 6 секунд, не перекрывает действие.
- Поощрение пишем про сегодняшнее: «Сегодня достаточно». Не про цифры и не про сравнение.
- Иконка поощрения — `streak`, подтверждения — `success`.
