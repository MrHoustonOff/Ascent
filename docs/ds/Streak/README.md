Серия дней: большое число, подпись и неделя из семи точек.

Предоставьте: количество дней и состояние каждого из семи дней (`done`, `rest`, `today`, пустой).

- День отдыха (`as-dot--rest`) сохраняет серию. Пропуск без отдыха показываем пустой пунктирной точкой, без красного.
- Огонёк и число — `streak`. Число — стиль `stat` с `tabular-nums`.
- Подпись говорит про сохранённое: «один день отдыха сохранён».
