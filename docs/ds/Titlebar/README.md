Кастомная шапка окна: название приложения слева, заголовок экрана по центру-слева, три кнопки справа. Заменяет системную рамку.

Предоставьте: название экрана и обработчики Свернуть / Развернуть / Закрыть из оболочки.

- Область перетаскивания — вся шапка. Блок кнопок помечайте `no-drag`.
- Кнопки: `as-ctrl`, закрытие — `as-ctrl--close`. Всегда задавайте `aria-label`.
- macOS: `as-titlebar--mac`, точки слева, глифы появляются при наведении на группу.
- Неактивное окно (`is-inactive` на `.as-window`) приглушает шапку.
- Не кладите в шапку ничего, кроме названия и кнопок окна. Поиск и действия уходят в содержимое.
