Контейнер для одной мысли: продолжить урок, показать серию, предложить отдых.

Предоставьте: `as-eyebrow` (рубрика), заголовок `as-h-headline` или `as-h-title1`, описание `as-p-callout`.

- Одна карточка — одна мысль и не больше одного действия.
- Большая `as-card--lg` — для главного блока экрана. Не вкладывайте карточки друг в друга.
