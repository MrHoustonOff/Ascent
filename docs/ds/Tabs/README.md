Сегментный контрол для 2–4 равноправных видов одного экрана (Сегодня / Неделя / Всё время).

Предоставьте: подписи и обработчик выбора. `role="tablist"`, `aria-selected`.

- Подписи короткие, одно слово. Активная вкладка поднята на `surface-raised`.
- Не используйте для навигации между экранами: для неё есть `Sidebar`.
