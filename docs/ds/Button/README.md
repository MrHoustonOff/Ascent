Кнопка действия. Четыре вида: `primary`, `secondary`, `ghost`, `danger`; два размера: обычный и `as-btn--lg`.

Предоставьте: подпись-глагол, при необходимости время («Продолжить · 12 мин»).

- На экране одна `primary`. Ей отдают самое важное и мягкое действие: продолжить урок.
- `ghost` — для необязательного: «Пропустить на сегодня». Не ставьте её рядом с `danger`.
- `danger` — только для необратимого, с подтверждением. Пропуск дня — не опасность.
- Минимальная высота — `hit-min` (32px). Отключённая кнопка — `disabled`, не меняйте её цвет вручную.
